YOUR MEETINGS, WITH YOUR AI TOOLS

Bring the right context.
Keep control of the rest.

Tagalong 3.4.1 includes a Claude Desktop extension and a private ChatGPT setup kit. Enable access to a library folder to make its supported meeting text available for search and retrieval. ChatGPT requires additional setup and remains unvalidated in the live client.

✳ Claude DesktopAvailable

Your meetings inside Claude.

Install the local extension to search meeting text and explore Summary, Tasks, Transcript, and Notes in an interactive workspace.

Setup & sharing details
  1. In Tagalong Settings → Claude & ChatGPT, choose a library folder and enable “Allow AI assistants to read this folder.”
  2. Click Install in Claude. After installation, close the extension popup and use Claude Settings → Extensions → Configure to choose the same folder.
  3. Ask Claude to search Tagalong and show a meeting. Restart Claude if it does not discover the tools.

Current and future supported meeting text in that folder is available for retrieval. Audio and images are excluded; task status is read-only. Retrieved excerpts enter Claude’s conversation. The connector enforces folder access in its code, not through an OS sandbox.

◎ ChatGPTSetup kit

A private MCP tunnel.

This setup requires OpenAI Secure MCP Tunnel, developer-mode access, and tunnel credentials. Your Mac must stay awake with the tunnel running.

Setup requirements & limits

The included kit requires Node.js 20+, the official tunnel client, workspace access, tunnel management/use permissions, and a private runtime API key. It is not a public-directory or universally one-click connection.

The same enabled library folder limits retrieval. Retrieved text enters your ChatGPT conversation. Interactive rendering in ChatGPT has not been validated; saving the kit does not establish a connection.

Folder access includes current and future supported meeting text. Revoking access stops future retrieval; it does not remove text already sent to a provider. Setup guide ↗

LOCAL FILES. DELIBERATE SHARING.

Your Mac is home base.

Your meeting library lives in a folder you control. Cloud services power transcription and AI features. Here’s where the boundaries are.

▱

Saved on your Mac

Transcripts, personal notes, visual notes, and audio you retain are saved as local files. Library search reads meeting text on your Mac.

You choose the folder. A folder in iCloud Drive or another sync service follows that service’s settings.

↗

Sent for processing

Live transcription uses on-device speech recognition where supported, with a cloud fallback. Speaker transcription sends audio for cloud processing after recording.

Summaries, enhanced notes, visual notes, and AI questions send the relevant text or context to AI services. Some processing starts automatically after you stop recording.

✓

Shared by your choice

Task export sends selected task content to the destination you choose. MCP connections retrieve supported text from the library folder you explicitly enable, including future meeting files.

Provider retention and workspace policies apply to shared content. Removing a local file or revoking access does not recall content already sent.

Two ways to use AI: the subscription routes requests through Tagalong’s backend to providers. A private license uses your own provider API keys for direct requests. Neither option makes all processing offline.

A FEW THINGS TO KNOW

Good questions.

Need a hand?
support@tagalongai.com

What’s included in the Free tier?

Free includes five meetings per month, microphone recording, basic AI summaries, Markdown export, and speaker editing. Pro adds the full feature set, including conference audio, AI assistance, enhanced notes, visual notes, search, and task export.

Does a bot join my meetings?

No. Tagalong records from your Mac using microphone or system audio capture. Give participants appropriate notice and get any permission you need before recording.

Does everything run offline?

No. Your saved files and library search are local. Live speech recognition can run on-device where supported, but cloud transcription and AI features send audio or relevant text for processing. See what stays local and what is sent.

Can I keep my own notes?

Yes. Take personal notes during the meeting and enhance them with transcript context afterward. The app preserves the original notes so you can revisit your own wording.

Do exported tasks stay in sync?

No. You select tasks and initiate one-way creation in a destination. Later edits or completion do not synchronize between Tagalong and the task manager. Destination setup and exported fields differ; monday.com currently creates named items without column mapping.

Can I connect Claude or ChatGPT now?

The public v3.4.1 release includes the Claude Desktop extension and a ChatGPT setup kit. Claude supports an interactive meeting workspace. ChatGPT requires a private Secure MCP Tunnel and eligible account setup; its interactive rendering remains unvalidated. Read setup and sharing details.

Which Macs are supported?

Tagalong requires macOS 15 Sequoia or later and supports Apple silicon and Intel Macs. Download the DMG, install the app, and follow the getting-started guide for permissions and plan setup.
